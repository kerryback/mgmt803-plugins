# Profile

This file stays on your own computer, at `~/.claude/syllabus-to-trello/profile.md`. Don't commit it to a repository or share it.

**Time zone:** e.g., America/Chicago
**Trello board:** e.g., My Board. One list per course is created here.
**School calendar:** name and ID, e.g., School (`...@group.calendar.google.com`)
**Your email:** you@example.com. It is never added as an attendee on calendar markers.

## Calendar markers
- **Time:** 6:00 PM local
- **Length:** 15 minutes
- **Popup reminders:** 1 day before, and 2 hours before

## Lead-time policy
- Quizzes, discussion posts, short prep: 1 day early
- Written cases, reports, papers: 3 days early
- Major group work, presentations, multi-week work: 5–7 days early, plus a start or draft card

## Submission conventions
- File naming: e.g., Lastname_Firstname_<Assignment name>
- Anything else your program requires on every submission, such as an honor-code statement
